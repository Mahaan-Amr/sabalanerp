## What to build

Make the shared dashboard sidebar read as one continuous curved neumorphic control below the full-width header. Collapsed navigation and footer actions are centered and dimensionally consistent, and expanded navigation retains readable semantic hover contrast in both themes.

## Acceptance criteria

- [ ] The transparent outer sidebar layer remains removed while the curved inner rail remains visible.
- [ ] The curved rail uses one continuous semantic surface across its top control, navigation, and footer.
- [ ] The sidebar starts eight pixels below the full-width header in open and closed states.
- [ ] Every collapsed navigation icon is geometrically centered within its interactive control.
- [ ] Collapsed theme and logout controls have identical height and width.
- [ ] Expanded theme and logout actions retain their horizontal layout and existing behavior.
- [ ] Navigation labels remain readable when hovered in dark and light themes, including inactive parent destinations while a child route is current.
- [ ] Existing navigation destinations, workspace selection, theme switching, logout, and responsive drawer behavior are unchanged.
- [ ] Browser-level Design System acceptance covers the visible geometry and contrast.
