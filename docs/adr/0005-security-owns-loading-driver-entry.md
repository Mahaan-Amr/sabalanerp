# Security owns loading driver entry

Status: superseded by ADR-0006

Logistics requests a driver for a specific draft بارگیری, but گارد assigns the waiting queue turn through ورود برای بارگیری. This keeps the physical gate decision with گارد while Logistics remains responsible for contract rows, quantities, and final loading correctness; direct Logistics selection from the queue was rejected because it bypassed the gate confirmation step and blurred operational ownership.
