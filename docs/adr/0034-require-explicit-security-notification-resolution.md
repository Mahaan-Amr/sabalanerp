# Require explicit security-notification resolution

Opening a new-browser or similar account-security notification only navigates to the highlighted session in the Self-Service Personal Area; it does not mark the alert resolved or revoke access. The alert remains unread until the user explicitly acknowledges the activity as theirs or confirms it was not theirs, in which case the identified session is revoked and password change is strongly offered. This replaces ambiguous browser-native prompts while preserving deliberate, accountable security actions.
