# Company Manager owns compensation proposals

Sabalan has no Hiring Manager position, so `HIRING_MANAGER` is retired as an active authority, responsibility, workflow actor, and persistent QA persona. The single global Company Manager responsibility assigned to `behpour` creates compensation proposals in Human Resources; Payroll preparation, Payroll approval, Finance approval, and Applicant acceptance remain separate, while immutable historical labels are retained only as legacy evidence and no named individual receives a full-access exception.
