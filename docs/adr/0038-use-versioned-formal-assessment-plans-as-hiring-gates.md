# Use versioned Formal Assessment Plans as hiring gates

The Company Manager-owned, per-Application Formal Assessment Plan supersedes the assessment-policy limitation recorded in ADR 0029. A plan must explicitly select no formal assessments or select any of DISC, EQ, and BIG FIVE with an execution method for each selection. Every selected assessment requires a valid completed result before the Formal Assessments lifecycle gate completes; revisions preserve plan and result lineage, and no result calculates a hiring outcome.

Recruitment Checklist Templates remain the authoritative source for reusable pre-identity checklist requirements. They are not a prerequisite for the separate Formal Assessment Plan, whose policy and ownership are now explicit in the domain model and Issue #242.
