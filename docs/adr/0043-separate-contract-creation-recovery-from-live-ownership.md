# Separate Contract Creation Recovery from Live Ownership

A Contract Creation Draft does not exist merely because a user opened or navigated through the blank wizard. It begins only after the creator commits business data that differs from the blank wizard, such as an explicitly changed Contract date, selected customer or project, saved product, delivery, or payment entry. The Draft is private to its creator and uses one renewable 75-second writer lease across that creator's browser locations; a live competing location sees one takeover decision, while an expired lease leaves only the ordinary resume-or-discard recovery decision. Browser and server recovery share a seven-day lifetime measured from the last meaningful change. Takeover immediately revokes the old writer and restores the newest saved recovery, explicit discard erases the contents everywhere while retaining only a minimal discard audit fact, and successful creation clears all recovery and ownership state. This separates durable recovery from transient presence, prevents an untouched wizard from producing false ownership warnings, and preserves exactly one writer without sacrificing the latest saved progress.
