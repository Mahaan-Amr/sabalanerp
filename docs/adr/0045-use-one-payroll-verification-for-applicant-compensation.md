# Use one Payroll verification for Applicant compensation

Company Management continues to own each versioned Applicant compensation proposal, but one independently permissioned Payroll verifier now checks its component classification and Payroll-policy correctness before Candidate presentation; the prior preparation, Payroll-manager approval, and Finance approval chain is retired prospectively because its four-person handoff imposed disproportionate delay without changing proposal ownership. The verifier returns an invalid package rather than editing it, an eligible Human Resources Broad-Manager Override may self-verify only through a separate audited action, Finance remains independently responsible for physical collateral through Accounting-destination duties, and historical actors, approvals, and offer versions remain immutable and deterministically compatible.
