# Use workspace-scoped shared duty decisions

Cross-workspace approval, rejection, and verification work is one Shared Cross-Workspace Decision Duty projected into My Duties for every currently eligible actor, while execution and custody work remains individually accountable. A source actor may participate only when their centralized effective access includes administration of the destination workspace plus edit-capable access to the required feature, or when they are global ADMIN; that self-decision is immediate and distinctly audited without a separate override dialog or explanation, while ordinary rejection, return, reassignment, strict two-person, source-version, and data-integrity requirements remain unchanged. Every duty definition declares its accountability model and may prohibit workspace-administrator override, with current HR work items, hiring-collateral controls, and future Manual Outage Exit duties protected initially. The first committed shared result wins atomically, bounded History follows current permission, individually assigned takeover remains explicit and reasoned, and the workspace navigation badge combines current My Duties with Available work added or changed since that User last opened Available. Existing open decisions migrate once to the shared model with preserved assignment history and a `MIGRATED_TO_SHARED_DECISION` audit event; closed and execution duties are unchanged. This decision supersedes ADR-0044 only where that ADR restricts self-decision to reason-gated global ADMIN and supersedes the assigned-only queue and badge rules in the earlier project-wide duty-engine specification.
