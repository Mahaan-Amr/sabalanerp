# Retire manual Start Preparation tasks

Start Preparation now exposes one read-only status summary derived from the canonical contract, Payroll Participation, and Employment Insurance Enrollment evidence instead of allowing ad hoc `HrOnboardingTask` creation or completion in the Hiring Case. The legacy rows and completion endpoint remain temporarily for historical compatibility, while creation returns an audited `410 Gone` and release promotion fails closed on open manual tasks, missing or duplicate system rows, or status drift; this deliberately trades ad hoc flexibility for one accountable source of truth without silently rewriting history. The creation endpoint may be removed only in the release after one complete cycle with zero deprecated calls, zero open manual tasks in Production, and every supported frontend upgraded; the legacy completion endpoint may be removed when the Production audit reports zero open manual tasks.
