# Reconcile Candidate–Personnel identity before linking

National Code creates a potential same-person match but never silently merges conflicting Candidate and Personnel identities. An Application preserves its own submitted identity claim, hard conflicts create an independently permissioned shared Human Resources resolution that blocks identity clearance and pre-activation progression, and post-conversion repair is a report-first atomic relinking operation that preserves prior conversion evidence; any obsolete Personnel erasure remains a later, separately previewed and ADMIN-authenticated action because coupling repair to deletion risks destroying valid recruitment history.
