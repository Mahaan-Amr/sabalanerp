# Review paper employment contracts through Accounting duties

Human Resources records and submits each immutable signed paper employment-contract version, while Accounting approves or returns it through a minimum-evidence Shared Cross-Workspace Decision Duty without Recruitment Case access. Recording and verification use independent permissions; an Accounting workspace administrator or global ADMIN holding both may self-verify only with the managerial-override audit marker, returns and pre-decision withdrawals create separately timed Human Resources correction duties, and the ambiguous legacy finance-evidence permission retires through a report-first cutover because direct source-workspace review conflates authority and exposes unrelated hiring evidence.
