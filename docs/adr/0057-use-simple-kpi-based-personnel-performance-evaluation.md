# Use simple KPI-based personnel performance evaluation

Personnel performance evaluation uses one active, versioned Evaluation Profile per Personnel, containing weighted measurable indicators, targets, units, and preferred directions. An authorized Responsible Supervisor may evaluate assigned Personnel, while a Human Resources Manager with an independent action permission may evaluate any Personnel in the permitted HR scope. The evaluator enters all actual values manually for an evaluation date, the system calculates the weighted score and five-level badge, and the same evaluator may save a draft and finalize it without a separate review queue; missing values block finalization but never become zero. Any number of new evaluations may be finalized during a month or on the same day, and monthly grouping is for reporting rather than uniqueness. The evaluation date defaults to today, may be changed to another non-future date in the same month, and the system records the actual finalization time. Indicator scores stop at one hundred; zero-target lower-is-better indicators score one hundred only when the actual value is zero, and otherwise score zero. Final results use the bands below sixty, sixty to below seventy-five, seventy-five to below ninety, ninety to below one hundred, and exactly one hundred. The current badge comes only from the newest effective final result, while older results remain history. A new evaluation is an independent observation and never replaces an earlier result; a correction replaces only its identified locked result through a reasoned correction version. The supplied workbook contributes profile definitions only, including the completed HR01 definition, and its sample Personnel names and values are not imported. This deliberately supersedes ADR-0024: operational values now calculate performance because the business prefers a short, understandable workflow over mandatory criterion-level human judgment and evidence review. The evaluator identity, authority source, profile version, inputs, calculation, correction lineage, access changes, and finalization remain auditable, and no result automatically changes compensation, promotion, discipline, or employment. Existing final results remain read-only and supply the badge until the first new final result; existing unfinished drafts are not converted. Daily use is limited to Evaluation, Profile Management, and History, and interface labels, hints, descriptions, actions, and errors use short plain Persian without exposing technical storage or integrity terms.
