# Map Sepidar accounts into a governed target chart

SabalanERP will own a newly governed Target Chart of Accounts rather than blindly copying Sepidar coding or ignoring it. Every active Sepidar account, balance, open item, and migrated reference must pass through an explicit reviewed mapping to the target Group, General, and Subsidiary structure, including accounting nature, financial-statement role, contra relationship, floating-detail eligibility, currency and tracking behavior, dimension rules, and effective dates. This preserves migration evidence without allowing legacy product structure to define the future ledger silently.
