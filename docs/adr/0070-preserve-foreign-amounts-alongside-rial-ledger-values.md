# Preserve foreign amounts alongside rial ledger values

The statutory ledger remains rial-denominated, while each foreign-currency journal line preserves its original amount and currency, exchange rate, rate date, rate source, and whole-rial equivalent. Period-end remeasurement and realized exchange differences occur only through separately posted vouchers under versioned rules. Multi-currency capability ships in the complete replacement even when initially disabled for an entity with no current foreign transactions.
