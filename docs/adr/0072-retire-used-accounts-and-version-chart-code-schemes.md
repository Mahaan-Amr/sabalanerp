# Retire used accounts and version chart code schemes

An account with posted activity cannot be deleted, recoded, or given a different accounting nature. It may be retired for new posting and linked to an effective-dated successor, while mergers and balance moves use explicit mapped vouchers. Each Target Chart of Accounts owns a configurable Group, General, and Subsidiary code scheme that becomes structurally immutable after posting begins; later structural change uses a reviewed successor scheme and migration instead of rewriting historical meaning.
