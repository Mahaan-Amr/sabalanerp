# Hard close only through a reconciled close run

A Posting Period or Accounting Fiscal Year reaches Hard Closed only through a reproducible Close Run after drafts, unresolved exceptions, suspense balances, and applicable receivable, payable, bank, check, inventory, fixed-asset, payroll, and tax differences are resolved. One explicitly authorized Accounting Manager may complete the run without a second actor after strong confirmation; the run preserves its checklist, trial-balance and control-report hashes, generated vouchers, actor, reason where applicable, and immutable audit. Reopening is a separately reasoned and strongly confirmed exception that retains the prior close evidence. Late events preserve actual and recorded times and normally adjust an open period with a prior-period reference rather than being backdated into Hard Close.
