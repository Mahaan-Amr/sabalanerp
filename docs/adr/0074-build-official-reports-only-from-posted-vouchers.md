# Build official reports only from posted vouchers

Official ledgers, T-accounts, trial balances, balances, and financial statements derive only from posted vouchers and remain reproducible from recorded book, period, mapping, policy version, filters, and as-of time. Management may request a separately labeled draft-inclusive preview, but draft and posted totals are never silently combined and a preview cannot be represented or exported as official accounting evidence.
