# Use effective-dated line tax rules and immutable reference chains

Taxability, exemption, rates, invoice type and pattern, discounts and other allocations, and rounding are determined per invoice line by a source-cited, effective-dated Tax Rule. Every line snapshots the rule version, raw calculation, rounded result, and allocation evidence so later law changes do not rewrite history. Original, corrective, cancellation, and sales-return Tax Invoices form an immutable reference chain using their distinct tax identities.
