# Build financial statements through versioned mappings

Financial statements are generated from posted journal lines through effective-dated Financial Statement Mapping versions, never inferred from an account code or broad account type. The supported set includes financial position, profit or loss, comprehensive income when applicable, changes in equity, direct and indirect cash flows, notes and breakdowns, prior-period comparatives, and a comparative opening statement when material restatement requires it. Internal cash transfers are excluded from external cash flows, and every reported amount remains reproducible and drillable under the mapping and classification versions recorded for that report.
