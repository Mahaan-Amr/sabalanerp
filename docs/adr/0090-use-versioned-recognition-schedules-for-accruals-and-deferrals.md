# Use versioned recognition schedules for accruals and deferrals

Prepayments, deferred income, accrued expenses, provisions, and recurring accounting events use versioned schedules with source evidence, recognition term, estimate basis, account and dimension rules, rounding, and posting policy. A schedule may create labeled proposals or post automatically only through the governed posting controls; changes affect declared future periods, cancellation leaves prior posted vouchers intact, and correction uses linked entries. Due, expired, unsupported, or unreviewed schedules become explicit close exceptions.
