# Migrate Accounting through idempotent lineage-preserving runs

Every migration execution records its source package and hash, tool and mapping versions, scope, record-level source-to-target disposition, rejections, counts, totals, and output integrity. It previews and validates before commitment, never guesses an invalid account into suspense, and is idempotent on retry. Corrected mappings create successor runs without erasing earlier evidence. Parallel acceptance covers at least two complete monthly periods including one full close, and every control total, open item, financial instrument, inventory identity, asset, payroll control, tax result, and report difference is explained; no unknown tolerance is accepted.
