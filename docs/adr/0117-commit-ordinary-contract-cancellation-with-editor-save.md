# Commit ordinary Contract cancellation with the editor save

Selecting cancellation inside the ordinary Sales Contract editor records a pending choice; the explicit save commits the complete edited commercial snapshot and cancellation in one transaction. Immediate cancellation followed by a separate save left Contracts cancelled even when their edits failed, so the editor must retain the pending choice on failure and permit withdrawing it before saving. Cancellation permissions, financial correction authorization, audit and reporting evidence remain mandatory; existing expiry and reactivation rules are outside this change.
