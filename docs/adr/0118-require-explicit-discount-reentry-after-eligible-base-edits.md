# Require explicit discount reentry after eligible base edits

An authorized Contract edit that changes the eligible stone subtotal must not retain stale positive-discount evidence or silently change the agreed amount or percentage. Sales must explicitly enter the discount amount or percentage for the new subtotal; changing only the entry mode does not count, and a subsequent subtotal change invalidates that entry. Invalid entries remain visible and block saving with actionable Persian feedback instead of being clamped. Both the editor and the backend save boundary enforce consistency before a replacement financial draft can capture it. An unchanged subtotal preserves the historical discount snapshot and saved range; explicit new entry uses the applicable range. Previously approved financial evidence remains immutable and financial approval retains its independent reconciliation gate.
