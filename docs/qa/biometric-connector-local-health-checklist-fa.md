# چک‌لیست دستی سلامت اتصال‌گر BioMini در محیط محلی

این چک‌لیست ابتدا اتصال و نمایش مشخصات دستگاه را بررسی می‌کند. مرحلهٔ ثبت اثر انگشت را فقط زمانی ادامه دهید که پروفایل راننده فعال و اطلاعات گواهینامهٔ او کامل باشد.

## آماده‌سازی

- [ ] اسکنر BioMini Slim 2 به USB متصل است.
- [ ] پروژه موجود `sabalanerp-local` سالم است: `npm run docker:local:ps`.
- [ ] در یک PowerShell جداگانه، از ریشه مخزن `npm run biometric:local:up` را اجرا کنید.
- [ ] ترمینال پیام `Sabalan biometric connector listening on 127.0.0.1:47631` را نشان می‌دهد و باز می‌ماند.

## بررسی صفحه

- [ ] با همان origin دقیق `http://127.0.0.1:3000` وارد ERP شوید.
- [ ] صفحه «وضعیت اسکنر اثر انگشت» را باز کنید.
- [ ] خطای `ERR_CONNECTION_REFUSED` برای `127.0.0.1:47631` دیده نمی‌شود.
- [ ] وضعیت دستگاه «در دسترس» است.
- [ ] مدل `BioMini SLIM 2` نمایش داده می‌شود.
- [ ] سریال با `SBBM-SLIM22024060000000873053007` برابر است.
- [ ] نسخه SDK برابر `3.11.1.595` است.
- [ ] صفحه ثبت واقعی اثر انگشت را «فعال» اعلام می‌کند.

## پیش‌شرط ثبت راننده

- [ ] وضعیت پرسنل فعال است.
- [ ] در صفحه «عملیات خودرو»، شماره، کلاس و تاریخ انقضای آیندهٔ گواهینامه ثبت شده است.
- [ ] وضعیت پروفایل راننده `ACTIVE` است.
- [ ] صلاحیت جاری راننده `ELIGIBLE` است.
- [ ] ثبت بیومتریک فعال دیگری برای راننده وجود ندارد.
- [ ] با فشردن «ثبت بیومتریک با اتصال‌گر»، سامانه پیش از اسکن روی مرحلهٔ انگشت اشاره راست متوقف می‌شود.
- [ ] پس از قراردادن انگشت اشاره راست، «اسکن انگشت اشاره راست» را بزنید و نتیجهٔ کیفیت و زنده‌بودن را ببینید.
- [ ] سامانه پیش از فرمان دوم متوقف می‌شود و صریحاً می‌خواهد انگشت راست کاملاً برداشته شود.
- [ ] انگشت اشاره چپ را قرار دهید و «اسکن انگشت اشاره چپ» را بزنید.
- [ ] فقط پس از ثبت مستقل هر دو انگشت، پیام «ثبت بیومتریک ذخیره شد» نمایش داده می‌شود.
- [ ] تصویر خام اثر انگشت نمایش داده یا ذخیره نمی‌شود؛ فقط انگشت ثبت‌شده، کیفیت و تأیید زنده‌بودن نمایش داده می‌شود.

## خروجی‌هایی که برای بررسی ارسال کنید

- متن کامل خروجی ترمینال `npm run biometric:local:up`، بدون فایل‌های کلید یا محتوای `connector.json`.
- متن پاسخ Network مربوط به `GET http://127.0.0.1:47631/v1/status`.
- متن پاسخ درخواست backend مربوط به `POST /api/biometric-connector/diagnostics/result`.
- هر خطای Console، با حذف token، cookie و headerهای احراز هویت.

## پایان کار

- [ ] با `Ctrl+C` اتصال‌گر foreground را متوقف کنید.
- [ ] `npm run biometric:local:reset` را اجرا کنید تا backend به حالت simulator برگردد.
