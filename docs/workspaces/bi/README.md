# Business Intelligence Workspace

The Business Intelligence workspace is a management-only workspace for Sales BI in v1. It analyzes sales contracts, payments, deliveries, customers, products, discounts, and seller performance without embedding an external BI product.

## Access

- Admins can view all BI sales data.
- Managers with `bi:view` can view department-scoped BI sales data.
- Managers with `bi:admin` can view all-company BI sales data.
- Normal users do not have BI access.

## V1 Scope

- Executive command center with eight top-line sales signals.
- Drill-down tabs for seller performance, financial sales, products/customers, and delivery risk.
- Excel export for drill-down tables.
- PDF/print executive summary using the same Sabalan report header style as sales contract output.
- RTL Persian UI with Jalali ranges and Sabalan ERP theme colors.
