# پیشنهاد تصویری بازطراحی CRM — تأییدشده توسط کاربر

این بسته پیش‌نمایش مستقل است. برای این پیشنهاد هیچ فایل برنامه، رفتار CRM، داده یا سرویس اجرایی تغییر نکرده است. تصاویر داده‌های نمونه دارند و گزارش وضعیت واقعی مشتریان نیستند.

## مبنای طراحی

رنگ‌ها، فونت و سایه‌ها از توکن‌های فعلی Sabalan و فضای HR گرفته شده‌اند. سربرگ، فاصله‌گذاری، فیلترها، کارت‌ها و اقدامات در همه صفحه‌ها یک الگو دارند. داده‌های اصلی ابتدا و اطلاعات تکمیلی در بخش‌های بازشونده نمایش داده می‌شوند. جدول‌ها در موبایل به کارت تبدیل می‌شوند.

مراحل و دکمه‌های قبلی/بعدی ثبت مشتری با خروجی واقعی WizardProgressBar و WizardNavigation فضای فروش رندر شده‌اند. در پیاده‌سازی نهایی از همین رابط‌های استاندارد استفاده می‌شود؛ هیچ مؤلفهٔ سفارشیِ جایگزین ایجاد نمی‌شود. سایر بخش‌های تصاویر، ترکیب‌بندی پیشنهادی‌اند، نه صفحهٔ پیاده‌سازی‌شده.

## مرزهای ثابت

- هیچ مرحلهٔ منطقی، شرط، فیلد، اعتبارسنجی، مجوز، محاسبه، معنی ذخیره‌شده یا سابقه‌ای حذف یا تغییر نمی‌کند.
- اطلاعات اختیاری صرفاً جمع می‌شوند و همچنان قابل مشاهده و ویرایش‌اند؛ فیلدهای مشروط مطابق نوع مشتری/وظیفه فعلی نمایش داده می‌شوند.
- سه مرحلهٔ مشتری عادی و دو مرحلهٔ مشتری همکاری باقی می‌مانند. پرش بین مراحل مجوز تازه‌ای پیدا نمی‌کند؛ اعتبارسنجی فعلی حفظ می‌شود.
- فرم‌های پروژه و پیگیری به ویزارد جدید تبدیل نمی‌شوند؛ فقط ویزارد موجود مشتری، نمای مراحل فروش را می‌گیرد.
- شروع قرارداد تنها تحت شرایط فعلی فعال است. انتخاب نداشتن اقدام بعدی همان فیلد دلیل فعلی را نمایش می‌دهد.
- صفحهٔ جزئیات وظیفه یک نمونه است؛ مدارک و اقدامات ویژهٔ هر نوع وظیفه طبق قرارداد فعلی نمایش داده خواهند شد.
- صفحات مشترک با فروش و فروش همکار، لینک‌های مستقیم، بازگشت به قرارداد و بازیابی حفظ می‌شوند.
- تصاویر تعداد محدودی ردیف نمونه نشان می‌دهند. همه داده‌ها و سوابق واقعی از مسیر فعلی خواهند آمد.

## مرور

`gallery.html` گروه‌ها و لینک تصاویر کامل را نشان می‌دهد. `index.html` پیش‌نمایش HTML هر صفحه را دارد؛ از پارامتر `page` استفاده می‌کند. کنترل‌های نمونه به CRM متصل نیستند. کاربر این طرح را تأیید کرد و پیاده‌سازی در CRM انجام شد. تصاویر این پوشه همچنان تصاویر پیشنهادی اولیه هستند، نه تصویر نسخهٔ اجراشده.
