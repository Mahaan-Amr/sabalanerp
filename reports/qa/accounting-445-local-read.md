# Accounting reviewable-list local read measurement (2026-11-15)

The existing `sabalanerp-local` Compose project was verified with `docker compose -f docker-compose.local.yml ps` before these reads. Measurements used the local PostgreSQL service on port 55432, an active internal admin reviewer, and `listAccountingContracts({ view: 'reviewable', page: 1, pageSize: 50 }, actor)` through the authenticated service seam. No production release or production-scale qualification was performed.

The local database held 869 ordinary contracts and 34 Partner internal rows visible to the reviewer before correcting the reviewable population. The original 50-row read took 8,876 ms, 11,592 ms, and 13,522 ms in three observed runs. Temporary stage profiling showed 2,400–7,109 ms in the shared Partner authorization and evidence scope; the ordinary projection fetched 869 rows in about 154–193 ms. The remaining wait was predominantly the Partner preparation-document path after the scope, not ordinary row hydration (about 200 ms for dates and 30 ms for collections in the profiled run).

Caching actor grant resolution within the existing read snapshot and reusing the validated commercial state in preparation reads reduced the first observed 50-row run to 5,846 ms. Subsequent runs varied. Restricting reviewable Partner rows to committed Cases and reading only the preparation overlay for Cases with an existing financial record yielded 3,432 ms and 4,020 ms first-page samples, with 896 total rows (869 ordinary and 27 committed Partner). Page 2 took 3,543 ms and 3,395 ms. These are local observations, not a p95 or a production admission result.

The reviewable Partner rows were compared field-for-field with the complete legacy Partner list for each committed Case, including accounting values and source-specific actions. The local integration test first failed because the prior reviewable result included uncommitted Cases; after the change it passed. The complete Partner list still includes its existing historical population. Production-shaped authenticated API timing, concurrent mutation/revocation, and the production p95 under three seconds remain qualification gates for the coordinated release.
