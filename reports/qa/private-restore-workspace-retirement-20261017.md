# Retired independent restore working copies

The completed independent restore trials left temporary application file copies
and six terminal tool containers. On 2026-10-17 the reviewed one-use fixture
retired those exact containers, the private `uploads`/`storage` working trees
and the redundant plaintext physical-base tar. These are diagnostic working
copies, not healthy recovery points. A future full trial must restore its file
workspace again; the old working paths are no longer a running application proof.

Before deletion, the fixture held both the private drill FD9 lock and backup
storage lock, reread both complete encrypted archive hashes and their healthy,
inactive/unheld metadata, verified the immutable image archive and retained
encrypted physical component, and captured every selected container's exact
terminal state and bounded native-owned log. It rechecked all remaining Docker
mount references before deleting exact owned paths. A private mount namespace
and mountinfo checks excluded host mounts and later propagation into traversal.
Independent review found and verified fixes for mount traversal and unbounded
log buffering before execution.

Actual free space increased from **2,467,180,544** to **3,761,569,792 bytes**:
**1,294,389,248 bytes** reclaimed. Both full restore-verified encrypted recovery
points, the verified image archive, independently decryptable encrypted physical
component, keys and evidence remain. The private PostgreSQL container retained
its exact start time. All eleven stable foreign service identities/start times
remained unchanged. No production application or database was updated.
