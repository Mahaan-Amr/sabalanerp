# Root-confined file ports and Dispatch composition

The private file owner can bind existing private descendant roots without creating another completion, capacity or version owner. Branded ports confine keys and historical reads to their root; moves require the same actual owner. Dispatch runtime accepts an explicitly injected port and shares it between its repository and adjustment preparer. Ordinary construction remains unchanged.

Seven native cases passed in the existing `sabalanerp-local` candidate volume: sibling isolation and sealing, unsafe roots/keys and forged ports, sequential and concurrent directory replacement, same-owner relocation with stale/foreign refusal, delayed upload destruction, and real Dispatch storage publication/tombstoning. A deterministic paused-filesystem regression first failed with a missing rejection, then passed after synchronous whole-batch comparison of pinned directory identities. No await separates comparison from commit.
